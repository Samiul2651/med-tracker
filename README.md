# Med Tracker

An offline Android app for following a doctor's prescription: tick off each dose,
get a reminder at each dose time, and see how many days and tablets are left.

- Works with no internet. The app has no internet permission at all.
- All data stays on your phone.
- Not medical advice. The app only stores what you type in.

## Install
1. On your phone, open this repo's **Releases** page (sign in to GitHub).
2. Download the latest `med-tracker-*.apk`.
3. Open it and allow "Install unknown apps" when Android asks.
